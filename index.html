    أداة 07
    
تحويل ZIP (أكواد) إلى APK

    
هذه الميزة غير ممكنة فعلياً داخل صفحة ويب — وإليك السبب والبدائل الحقيقية بدل زر لا يعمل.

  


  

    
⚠️ لماذا لا يمكن تنفيذها هنا؟

    

      بناء ملف APK حقيقي يحتاج إلى سلسلة أدوات بناء أندرويد كاملة: Android SDK، وGradle، وaapt (لتحزيم الموارد)، ومترجم Dex لتحويل الكود إلى صيغة أندرويد، وأخيراً توقيع الحزمة (Signing). هذه الأدوات ضخمة ومعقدة ولا يمكن تشغيلها داخل متصفح كملف HTML بسيط. أي زر يزعم فعل ذلك سينتج ملفاً لا يعمل فعلياً كتطبيق أندرويد — وهذا مضلّل، لذلك تم استبداله بهذا الشرح بدلاً من ميزة وهمية.
    

  


  

    
البدائل الحقيقية حسب نوع مشروعك

  


  

    
      🌐
      
PWA Builder

      
إذا كان مشروعك موقع ويب (HTML/CSS/JS) — يحوّله مايكروسوفت مباشرة إلى APK حقيقي وقابل للنشر.

    
    
      📱
      
Capacitor / Cordova

      
لتغليف مشروع ويب داخل تطبيق أندرويد أصلي مع وصول لميزات الجهاز.

    
    
      ⚙️
      
GitHub Actions + Gradle

      
لو كودك مشروع أندرويد حقيقي (Java/Kotlin) — يبني لك APK تلقائياً من المستودع بسحابة GitHub.

    
    
      🚀
      
Median

      
خدمة جاهزة تحوّل موقعك إلى تطبيق أندرويد/iOS دون كتابة كود بناء بنفسك.

    
  







  

    أداة 08
    
ضغط الملفات

    
ارفع ملفاً أو أكثر، اختر الصيغة، واحصل على أرشيف مضغوط جاهز للتحميل.

  


  

    
    

      🗂️ اضغط هنا لاختيار ملف أو عدة ملفات
    

    
    


    

      

        
        
      

    


    

    

      

        

          

          صيغ 7Z وRAR وTAR.ZST وTAR.XZ
          تحتاج محرّكات ضغط متخصصة (LZMA، خوارزمية Zstandard، أو مكتبة RAR المملوكة لشركة WinRAR)
          لا يمكن تشغيلها بشكل موثوق داخل صفحة ويب بسيطة. لتفادي إنتاج ملف لا يعمل فعلياً، الأفضل استخدام
          ZIP أو TAR.GZ من هذه الأداة (يعملان فعلياً وبالكامل)، أو برامج
          مخصصة على جهازك مثل 7-Zip أو WinRAR أو أداة zstd
          لو احتجت هذه الصيغ تحديداً.
